# Descripción del .gitignore + recomendaciones básicas.  

El fichero git ignore esta configurado de tal forma que se ignoren archivos con:
configuraciones locales, contraseñas, binarios y ficheros temporales como el cache.
Todo con el fin de evitar comprometer la seguridad de los colaboradores así como la inyección
de posible código malicioso.  

## Recomendaciones para un entorno de trabajo seguro.  

Se solicita que se haga uso de ramas protegidas a todos los colaboradores así como
solicitar contribuciones mediante pull request o forks y crear copias de seguridad en lugar de trabajar
con el repositorio orignial.
